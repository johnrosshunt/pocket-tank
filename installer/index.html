Install Pocket Tank

A tiny language model governs fish decisions on an ESP32-S3. Put it on your board from this page, and bring a tank you already keep up to date the same way.

Install

  1. Plug the board into this computer with a USB-C cable that carries data (some charge-only cables don't). The board's own USB-C port goes straight to the chip, no adapter needed.
  2. Click the button. Your browser asks which port to use: pick USB JTAG/serial debug unit (on Linux it may just say ttyACM0).
  3. Wait for the bar to fill. About {{TOTAL_MB}} MB goes over, which takes a minute or two. When it says Installation complete, the board reboots on its own: a new board into a fresh tank with two fry, a tank you already keep into the same tank, carrying on.
This browser can't talk to USB devices. Use Chrome or Edge on a desktop or laptop. Browser flashing only works on an HTTPS page (or localhost). Chrome or Edge, desktop · firmware {{VERSION}}

Updating a tank you already keep? Same button, nothing else to do. The installer never erases the board: it rewrites the app and the model, and the tank's save lives in a part of the flash it does not touch. Your fish, their names and colors, their trust and history, the badges, the sand dollars and everything you placed all stay. Every version since the first one loads the saves of every earlier one.

The dialog says Install either way, and shows the version it is about to write. If your tank is asleep (dark screen), press PWR first so the port shows up.

Start over

You don't need this page for that: hold BOOT and tap the glass, and the tank asks Reset tank?. Answer YES for two new fry.

If the board won't get that far, or you want the flash wiped clean before installing, this button asks first, then erases everything and installs fresh:

This browser can't talk to USB devices. Use Chrome or Edge on a desktop or laptop. Browser flashing only works on an HTTPS page (or localhost).

It shows an Erase device checkbox: tick it. Left unticked it installs like the button above.

Supported hardware

Supported

Waveshare ESP32-S3-Touch-AMOLED-1.8 (revision V1 and V2; the firmware tells them apart at boot). ESP32-S3 with 16 MB flash and 8 MB PSRAM, 1.8" 368×448 AMOLED, capacitive touch, IMU, RTC, battery charger. Around $35 with the screen and a battery.

The installer checks that the connected chip is an ESP32-S3. It can't tell which board the chip sits on, so on any other ESP32-S3 board it will flash fine and then show nothing: the display and touch drivers are for this panel. More boards later.

If something's off

The port list is empty, or the board isn't in it

A tank that is already running Pocket Tank may be asleep (dark screen): its USB port disappears while it sleeps. Press PWR once to wake it, then try again.

Otherwise, hold BOOT while you plug the cable in (or while tapping RESET). That forces the chip into its download mode, which always shows up as a port.

Try another cable and a port directly on the computer rather than a hub.

"Failed to initialize" or the install stops partway

Close anything else that may hold the port (a serial monitor, another tab with this page), unplug, replug, and click Install again. If it fails at the same place twice, hold BOOT while plugging in and retry; a tank you keep is still on the board, the install only ever rewrites the app and the model.

Linux: permission denied on the port

Add yourself to the group that owns /dev/ttyACM0 (usually dialout or uucp), then log out and back in: sudo usermod -aG dialout $USER

A backup of the tank before updating (optional, needs a terminal)

The update keeps the tank on its own, but if you like a copy first: with esptool installed (pip install esptool) and the board awake, esptool.py --chip esp32s3 read_flash 0x9000 0x6000 my-tank.bin saves the whole save area to a file, and esptool.py --chip esp32s3 write_flash 0x9000 my-tank.bin puts it back.

Windows: the port shows but the install fails to connect

Windows 10 and 11 have the driver built in. If the device appears with a warning in Device Manager, install Espressif's USB driver or use a different USB port, then retry.

What exactly gets written

Four pieces at fixed places in the chip's 16 MB flash: the bootloader, the partition table, the app, and the 7.5 MB four-bit model. The manifest.json next to this page lists them. The tank's save (the fish, the settings) sits in a separate 24 KB area at 0x9000 that none of the four cover, which is why an update keeps it; only the erase button above clears it. Everything runs on the chip; nothing is sent anywhere.

After it boots

Two fry appear in a fresh tank. Tap the water to feed them, rest a finger on the glass and they'll come to see you, drag across the glass to wipe algae, swipe sideways through the grass to trim it. A short press on PWR puts the tank to sleep and another wakes it (the tank decides how deep it sleeps); hold BOOT and tap the glass to reset the tank.
